# Vidu S2 数字人局域网纯净推流与弹幕交互中继系统

本套系统专为解决以下核心需求设计：
1. **彻底去除官方丑陋 UI**：抹除 Vidu S2 网页端的所有水印（`AI生成数字人 | Vidu S`）、计时器（`00:01`）、控制按钮、黑色边框。
2. **跨电脑 OBS 极清无损采集**：专为同局域网的另外一台电脑 OBS 设计，通过 OBS 内置的“浏览器源”直接拉取**纯净的数字人视频 + 纯净 TTS 语音**。
3. **全画幅比例自适应**：原生支持 **9:16（竖屏数字人）** 与 **16:9（横屏场景）**，自动按原始宽高比无畸变居中适配，支持透明通道。
4. **弹幕与动作指令中继 API**：对外开放标准 HTTP 接口，支持打字对话、动作干预，并已为**抖音/B站弹幕抓取助手**预留好自动交互通道。

---

## 快速使用步骤

### 1. 启动本地中继服务
双击运行目录下的：
```bash
启动中继服务.bat
```
终端会输出如下地址（系统已自动识别你的本机局域网 IP）：
* **本地控制台**：`http://127.0.0.1:8888/controller.html`
* **OBS 专属纯净源**：`http://192.168.0.20:8888/obs.html`

---

### 2. 在宿主浏览器中加载桥接扩展
在打开 Vidu 对话的浏览器中（只需操作一次）：
1. 在浏览器安装 **Tampermonkey（油猴）** 插件。
2. 创建新脚本，将工程目录下的 [`vidu-bridge-injector.user.js`](file:///f:/coding/Antigravity/vidu-web/vidu-bridge-injector.user.js) 内容完整复制粘贴进去并保存。
3. 刷新你的 Vidu 对话页面：
   - 页面上的计时器、水印、控制栏会自动被剥离隐藏，只呈现全屏纯净视频。
   - 插件会自动捕获底层 WebRTC 音视频轨，并连通本地 8888 中继服务。

---

### 3. 另一台电脑配置 OBS 采集
在另一台电脑打开 OBS Studio：
1. 在“来源”窗口点击 **`+` -> 浏览器 (Browser Source)**。
2. 配置参数：
   - **URL**：`http://192.168.0.20:8888/obs.html`
   - **宽度**：`1080`（如果是竖屏）或 `1920`（如果是横屏）
   - **高度**：`1920`（如果是竖屏）或 `1080`（如果是横屏）
   - **勾选**：`[√] 通过 OBS 控制音频`（声音会直接进入 OBS 混音器）
3. 点击确定，即可看到**画面极致纯净、无任何按钮、带原声的高清数字人直播流**！

---

### 4. 弹幕互动与动作干预（抖音弹幕助手接入）

#### 方式 A：在本地控制台手动测试
访问 `http://127.0.0.1:8888/controller.html`：
* **弹幕输入框**：输入任何观众弹幕或对话内容，回车发送，数字人会使用千问 TTS 结合大模型语音回答。
* **动作干预按钮**：预设了“比剪刀手”、“挥手打招呼”、“眨眼放电”、“双手比心”、“戴上墨镜”等动作，点击即可让数字人边说边做动作。

#### 方式 B：抖音弹幕抓取助手自动对接
你的弹幕抓取程序（无论是 Python、Node.js 还是现成工具）只要抓取到观众弹幕，直接发起一个 HTTP POST 请求：

```http
POST http://192.168.0.20:8888/api/chat
Content-Type: application/json

{
  "username": "观众昵称",
  "text": "欢迎主播，今天这套衣服真好看！"
}
```

触发指定动作（让数字人比心或换动作）：
```http
POST http://192.168.0.20:8888/api/action
Content-Type: application/json

{
  "action": "比剪刀手"
}
```
数字人会自动在直播间执行该动作并做出相应回应。
