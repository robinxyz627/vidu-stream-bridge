## ✨ 核心特性一览

### 1. 🖥️ 极致纯净数字人舞台 (Pure Full Stage)
* **全自动深度 DOM 净化**：进入房间瞬间自动剥离官方网页中的所有水印遮罩（`AI生成数字人 | Vidu S`）、通话计时器（如 `00:01`）、底部文本输入框、控制按钮、黑色多余遮挡。
* **全比例自适应无畸变**：原生支持 **9:16（竖屏数字人主播）** 与 **16:9（横屏全景）** 视口，根据数字人实际分辨率全屏居中拉伸，背景纯黑，无缝支持 OBS 抠像。

### 2. 📡 跨电脑 OBS 局域网极清无损采集 (WebRTC Relay)
* **专为双电脑/多电脑直播流设计**：工作台运行在主机 A 上，直播推流运行在主机 B 上的 OBS 中，无需采集卡、NDI 或屏幕截取。
* **原生浏览器源接入**：OBS 仅需添加“浏览器 (Browser Source)”并填入拉流链接，即可直接接收 **1080x1920 极清画质视频 + 纯净 TTS 语音**（声音直接进入 OBS 混音器），毫秒级低延迟。
* **主机 IP / 端口 / 域名完全可配置**：工作台界面内置 IP/域名/端口配置框，支持手动输入任意局域网 IP、自定义域名或内网穿透（frp/tailscale）地址，配置本地自动持久化保存，并提供**一键快速复制**。

### 3. 🔑 凭证本地持久化与自动化免密登录
* **一次保存，终身免密**：在客户端中粘贴 Cookie 或 JWT 凭证后自动加密写入本地 `config.json`（已加入 `.gitignore` 保护隐私），再次启动软件全自动静默激活。
* **官方跨域网关无缝注入**：底层深度注入 `service.vidu.cn` 跨域凭证，彻底解决官方频繁出现的 Claim 鉴权失败问题。
* **多角色自动同步**：自动从官方 API 检索并列出用户创建的所有专属自定义数字人角色，支持一键无感切换。

### 4. 📻 智能防爆冲弹幕交互引擎 (Anti-Congestion Priority Queue)
专为直播间弹幕洪峰设计，内置智能调度队列：
* **多级优先级调度**：
  * **P1（大额高价值礼物）**：绝对优先插队，任何时候立即响应，永不丢弃。
  * **P2（观众聊天提问）**：正常队列顺序响应。
  * **P3（新粉丝关注）**：次级插播。
  * **P4（进房与点赞）**：空闲时插播，拥堵时自动降级或舍弃。
* **话轮发音冷却保护**：内置可调节的发言间隔（默认 6.5 秒），防止多条弹幕指令同时注入导致数字人语音重叠打架。
* **智能垃圾水词过滤与去重**：自动过滤 `666`、`111`、`打卡` 等无意义灌水弹幕；12 秒内同用户发送的相同文本自动去重。
* **TTL 动态老化淘汰**：超过 25 秒积压未播报的旧弹幕自动丢弃，队列超载时优先舍弃低优先级点赞/进房，永不阻塞堆积。

### 5. ⚙️ 全模式可配置引导词模板 (Prompt Templates)
* 内置 6 种互动模式独立模板：**普通聊天**、**大额礼物重点感谢**、**日常小礼随和感谢**、**关注感谢**、**进房欢迎**、**连击点赞感谢**。
* 支持自由变量占位符：`{nickname}`（昵称）、`{gender}`（性别）、`{content}`（内容）、`{giftName}`（礼物名）、`{giftCount}`（数量）、`{diamonds}`（抖币价值）、`{count}`（点赞数）、`{time}`（北京时间）。
* 界面内支持实时编辑、保存至本地 `danmu_config.json`，修改后立即生效。

### 6. ⏰ 本地时间感知能力（北京时间自动对齐）
* 当弹幕中出现“时间”、“几点”、“日期”、“星期”、“什么时候”等时间关键词时，系统会自动在引导词句尾补充：
  > `（本地时间是{time}，如果需要回复，则使用这个时间为参考。）`
* 也可在任意模板中显式引用 `{time}`，让数字人精准掌握当下真实时间，避免对答出现时空错乱。

### 7. 🎭 肢体动作实时干预
* 预置一键动作干预按钮：`挥手打招呼`、`比剪刀手`、`双手比心`、`开心微笑`、`戴上墨镜`，可随时配合直播气氛让数字人做出对应动作。

## 🚀 快速上手

### 1. 环境准备
* 操作系统：Windows 10 / 11、macOS 或 Linux
* 运行环境：[Node.js](https://nodejs.org/) (建议 `>= 18.0.0`)
* 直播软件：[OBS Studio](https://obsproject.com/) (建议最新版)

### 2. 安装与运行
```bash
# 1. 克隆本项目仓库
git clone https://github.com/your-username/vidu-web.git
cd vidu-web

# 2. 安装项目依赖
npm install

# 3. 启动数字人工作台
npm start
# 或者双击运行根目录下的 start.bat
```

### 3. 配置登录凭证 (首次使用)
1. 启动工作台后，在右侧面板的 **🔑 凭证管理** 区域：
   * 在输入框中粘贴你的 Vidu 登录 Cookie 或 JWT 字符串。
   * 点击 **【⚡ 导入/更新凭证并写入本地永久保存】**。
   * *(或直接点击窗口右上角的【窗口内扫码登录】通过手机扫码快速登录)*。
2. 登录成功后，顶部状态条显示绿灯 `🟢 已激活: 用户名`，并自动加载出你的自定义数字人角色。
3. 点击 **【🎥 开始纯净开播】**，数字人即进入全屏纯净视频渲染模式！

## 📡 跨电脑 OBS 采集设置指南

当你在另一台电脑上进行直播推流时：

```
[ 工作台电脑 (A) ]                                [ 推流直播电脑 (B) ]
┌────────────────────────┐    局域网 WebRTC 传输    ┌──────────────────────┐
│  Vidu S2 工作台运行中   │ ─────────────────────> │ OBS Studio           │
│  IP: 192.168.x.x:8888  │   (极清视频 + 原生TTS)   │ (添加浏览器源即刻呈现) │
└────────────────────────┘                         └──────────────────────┘
```

1. 在工作台右侧卡片 **📡 跨电脑 OBS 局域网采集** 中，确认或修改你的主机局域网 IP（如 `192.168.1.50` 或自定义域名），点击 **【📋 复制】** 按钮获取拉流 URL：
   ```text
   http://<你的主机IP>:8888/obs.html
   ```
2. 在推流电脑上打开 **OBS Studio**：
   * 在“来源 (Sources)”面板中点击 **`+` -> 浏览器 (Browser)**。
   * **URL**：粘贴上方复制的链接（例如 `http://192.168.1.50:8888/obs.html`）。
   * **宽度**：`1080`（竖屏数字人）或 `1920`（横屏全景）。
   * **高度**：`1920`（竖屏数字人）或 `1080`（横屏全景）。
   * **勾选**：`[√] 通过 OBS 控制音频`（极重要！勾选后数字人语音将直接进入 OBS 混音轨道）。
   * 点击确定，OBS 画布上即可秒级呈现纯净无水印、带实时语音的数字人直播画面！

## 📻 弹幕抓取与转发协议规范 (重要：外部抓包工具对接)

> [!IMPORTANT]
> ### 架构解耦说明
> **本项目本体专注于“数字人纯净渲染、WebRTC 低延迟中继推流与智能防爆冲调度”，项目代码中不包含任何特定直播平台（如抖音、快手、B站等）的抓包反编译代码。**  
> 任何人都可以配合市面上任何开源或自研的弹幕监听工具（例如基于抖音直播伴侣的抓包工具、各类 Wss 弹幕监听器、Python 脚本等），只需在抓到弹幕后向本项目暴露的标准 HTTP Webhook 接口发送一条 JSON 请求，即可实现全自动实时互动！

### 1. HTTP Webhook 接口定义
* **接口 URL**：`POST http://<工作台主机IP>:8010/human`  
  *(备用兼容接口：`POST http://<工作台主机IP>:8888/human` 或 `/api/danmu`)*
* **请求方法**：`POST`
* **请求头**：`Content-Type: application/json; charset=utf-8`

### 2. 数据结构规范说明

| 字段名 | 类型 | 必填 | 适用事件 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `type` | string | **是** | 全部 | 事件类型，可选：`"chat"` (发言)、`"gift"` (送礼)、`"follow"` (关注)、`"enter"` (进房)、`"like"` (点赞) |
| `nickname` | string | 否 | 全部 | 观众昵称 (缺省默认为“热心观众”) |
| `gender` | string | 否 | 全部 | 观众性别：`"男"`、`"女"`、`"未知"` (缺省默认为“观众”) |
| `content` | string | `chat` 必填 | `chat` | 观众在直播间发送的发言文本 |
| `giftName` | string | `gift` 必填 | `gift` | 送出的礼物名称 (例如“小心心”、“保时捷”、“嘉年华”) |
| `giftCount` | number | 否 | `gift` | 送出的礼物数量 (缺省默认为 1) |
| `diamondCount` | number | 否 | `gift` | 礼物抖币/钻石总价值。系统根据此值判断是否达到大额礼物阈值 |
| `likeCount` / `count` | number | 否 | `like` | 连击点赞次数 (缺省默认为 1) |

---

### 3. 5 种事件类型的 JSON Payload 示例

#### ① 普通弹幕发言 (Chat)
```json
POST http://127.0.0.1:8010/human
Content-Type: application/json

{
  "type": "chat",
  "nickname": "小明",
  "gender": "男",
  "content": "主播今天穿的小裙子真好看！"
}
```

#### ② 收到礼物 (Gift)
> **大额礼物规则**：当 `diamondCount`（抖币价值）大于等于工作台上设置的阈值（默认 50 抖币）时，系统自动匹配 **大额礼物重点感谢模板** 并以最高优先级 (P1) 优先插播！低于阈值则采用日常小礼随和感谢模板。

```json
POST http://127.0.0.1:8010/human
Content-Type: application/json

{
  "type": "gift",
  "nickname": "榜一大哥",
  "gender": "男",
  "giftName": "嘉年华",
  "giftCount": 1,
  "diamondCount": 3000
}
```

#### ③ 粉丝关注 (Follow)
```json
POST http://127.0.0.1:8010/human
Content-Type: application/json

{
  "type": "follow",
  "nickname": "甜心小喵",
  "gender": "女"
}
```

#### ④ 进房欢迎 (Enter)
```json
POST http://127.0.0.1:8010/human
Content-Type: application/json

{
  "type": "enter",
  "nickname": "风清扬",
  "gender": "男"
}
```

#### ⑤ 连击点赞 (Like)
```json
POST http://127.0.0.1:8010/human
Content-Type: application/json

{
  "type": "like",
  "nickname": "热心市民",
  "gender": "男",
  "count": 20
}
```

## ❓ 常见问题排查 (FAQ)

### Q1: 另一台电脑的 OBS 浏览器源显示“等待视频流”或黑屏？
1. **排查主机 IP**：请检查工作台界面中显示的 IP 是否为两台电脑互通的局域网 IP（而非 `127.0.0.1`）。可以在推流电脑上 ping 主机 IP 检查网络是否连通。
2. **确认开播状态**：工作台必须处于【🎥 开始纯净开播】且远端数字人视频流已成功连接（工作台左侧舞台已显示动态画面）。
3. **防火墙放行**：Windows 防火墙可能会拦截 8888 与 8010 端口，请在弹出的防火墙提示中勾选“允许在专用网络通信”。

### Q2: 弹幕涌入时数字人说话声音互相重叠打架？
* 本系统内置**话轮发音冷却机制**。请在工作台右侧「📻 抖音直播伴侣弹幕中继」卡片中调整「话轮冷却」数值（建议设置为 `6.0` ~ `7.5` 秒），系统将严格等待当前数字人回答完毕并留出间隙后再注入下一条弹幕，彻底杜绝声音打架。

### Q3: 为什么数字人回答时没有做动作？
* Vidu 内置大语言模型会根据注入引导词自主判断是否做出肢体动作。若希望提高动作触发概率，可在「⚙️ 自定义各模式引导词模板」中适当加强动作提示（例如：“请回复ta，并配合做出开心的互动动作”）。
